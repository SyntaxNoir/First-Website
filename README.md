# Himank Sirandhana | CS & AI Portfolio

A responsive, single-page portfolio introducing Himank Sirandhana, a Computer Science and Artificial Intelligence student at Newton School of Technology. The site presents his interests, skills, education, featured work, and contact links in a cosmic-inspired visual design.

## Project Overview

This project is a lightweight front-end portfolio built with semantic HTML and CSS. Its purpose is to give visitors and hackathon judges a quick overview of the creator and his current technical focus.

The page is organized into these sections:

- **Home:** introduction, study program, and links to projects and contact information.
- **About:** background, interests, and goals.
- **Skills:** AI and machine learning, software development, and tools and foundations.
- **Projects:** a calculator concept presented as a featured project showcase.
- **Education:** current B-Tech program and areas of study.
- **Connect:** LinkedIn profile and a message form.

## Highlights

- Responsive layout with a CSS-only mobile navigation menu.
- Animated cosmic background, orbital artwork, and glass-inspired panels built with CSS.
- Semantic HTML structure and accessible section navigation.
- No JavaScript, framework, backend, or package dependencies are required.

## Technology

- HTML5
- CSS3, including Grid, Flexbox, responsive media queries, and animations
- Google Fonts: Outfit, Space Grotesk, and JetBrains Mono

## Run Locally

Open `index.html` directly in a browser, or serve the project directory locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Scope Notes

- The calculator in the Projects section is a visual mockup; its keypad does not perform calculations.
- The contact form uses a `mailto:` action with a placeholder email address, so it is not connected to a live message service.
